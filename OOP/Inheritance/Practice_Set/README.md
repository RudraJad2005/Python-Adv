# Inheritance Practice Set

This mini set mirrors the style of other Practice_Set folders. Each file contains small TODOs and a quick self-check you can run.

Files:
- 01_problems1.py — Single, multilevel, hierarchical inheritance and method overriding.
- 02_problems2.py — Multiple inheritance, mixins, and cooperative super() with MRO.
- 03_problems3.py — ABCs, properties, name-mangling ("private"), and composition vs inheritance.

How to run quick checks:
- Open a file and run it directly to see expected outputs.
- Complete the TODOs; re-run until the self-check prints PASS.

Happy practicing!
